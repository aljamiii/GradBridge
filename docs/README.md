# GradBridge — Evaluation Prep Docs

The course guideline says: *AI-generated code you can't explain = zero marks;
inability to do live modifications = zero marks.* These docs exist so every
member owns their features.

## How to use (per member, before each lab)

1. Read [00-architecture.md](00-architecture.md) — the shared skeleton
   (MVC, auth, services, caching, sockets). Everyone gets asked these.
2. Read YOUR file below, with the actual code open beside it.
3. Do the **practice modifications** at the end of each feature — at least the
   Easy + one Medium — with the app running, and commit them yourself
   (individual commit history is graded!).
4. Rehearse the viva Q&A out loud.
